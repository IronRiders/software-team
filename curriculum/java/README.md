# Java Curriculum

Welcome to the Java Curriculum! This curriculum is for those who are new to Java. It's okay if you have absolutely no experience in any programming language, if you already know a little Java, or anything in between.

Each week has a few codecademy lessons. Please do these lessons outside of software meetings. I highly recommend that you (that means you have to) read the attached extra documents from w3Schools. I also recommend- optionally- that you try some online java practice exercises.

### Overview

Week 1: Core Concepts
- Hello World
- Variables
- Object Oriented Programming

Week 2: Control Flow
- Conditions and Control Flow
- Arrays and ArrayLists
- Loops

Week 3: Advanced OOP
- String Methods
- Access, Encapsulation, and Static Methods
- Inheritance and Polymorphism

Week 4: Practice Project
- Debugging
- Two Dimensional Arrays
- Practice Project
